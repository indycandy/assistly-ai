# Assistly AI MVP

Prima base reale della piattaforma SaaS Assistly AI per Indy Candy Shop.

## Avvio

```bash
npm install
npm run dev
```

## Pubblicazione su Vercel

1. Crea un repository GitHub.
2. Carica tutti i file della cartella.
3. Su Vercel scegli Add New > Project.
4. Importa il repository.
5. Premi Deploy.

## Funzioni incluse

- Dashboard responsive
- Conversazioni demo
- Prodotti e FAQ modificabili
- Configurazione assistente AI
- Salvataggio locale
- Struttura Next.js + TypeScript
